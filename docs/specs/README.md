# Specs

Una carpeta por feature, creada con `/spec <feature>`:

```
docs/specs/<feature>/
├── spec.md       qué se construye (ingeniero + persona)
├── contexto.md   qué hay en el repo (Explore)
├── critica.md    alternativas más simples (crítico) + respuesta del ingeniero
├── revision.md   corrección, tests y seguridad (revisor)
└── notas.md      desvíos y decisiones durante la implementación
```
